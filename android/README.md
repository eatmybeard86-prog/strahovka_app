# Скриня для Android

Android-додаток відкриває вебзастосунок «Скриня» (https://oblik-roty-jkfx.onrender.com) у вбудованому вікні. Усі дані, ролі (лише перегляд / редактор / адміністратор), права, вхід із SOS-паролем і функції лишаються на сервері, тож у додатку доступне рівно те саме, що й у браузері, з тим самим логіном і паролем. Нові можливості сайту з'являються в додатку одразу після розгортання сервера, без оновлення APK.

Що додає сам додаток: іконку на робочому столі, вхід, що зберігається між запусками, екран «Сервер прокидається» поки безкоштовний Render стартує, збереження CSV у «Завантаження», вибір фото чека з камери або галереї (знімок з камери лишається в тимчасовій теці додатку, а не в галереї, і дозвіл на камеру не потрібен), діалоги підтвердження, кнопку «Назад». Посилання на інші сайти відкриваються у звичайному браузері.

## Встановлення

1. На телефоні відкрийте https://github.com/eatmybeard86-prog/strahovka_app/releases/latest/download/skrynya.apk
2. Відкрийте завантажений файл і дозвольте встановлення з цього джерела (браузера чи «Файлів»).
3. Запустіть «Скриня» і увійдіть своїм логіном і паролем.

## Збірка

APK збирає GitHub Actions (`.github/workflows/android.yml`) при кожній зміні в `android/`; на гілці `main` він публікується як новий реліз. Запустити вручну: Actions → Android APK → Run workflow.

Локально (потрібні JDK 17 і Android SDK): `cd android && ./gradlew assembleRelease`.

## Постійний ключ підпису (за бажанням)

Без ключа кожна збірка підписується тимчасовим ключем, і нову версію Android встановить лише після видалення старої (дані на сервері не зачіпаються, просто доведеться увійти знову). Щоб оновлення ставилися поверх, один раз створіть ключ і додайте секрети в Settings → Secrets and variables → Actions:

```bash
keytool -genkeypair -v -keystore skrynya.jks -alias skrynya -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 skrynya.jks   # вміст → секрет SIGNING_KEYSTORE_BASE64
```

Також `SIGNING_STORE_PASSWORD` (пароль сховища) і, якщо відрізняються від типових, `SIGNING_KEY_ALIAS` та `SIGNING_KEY_PASSWORD`. Файл `skrynya.jks` бережіть, у репозиторій його не додавайте.
