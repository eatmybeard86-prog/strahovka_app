# Облік роти

Веб-застосунок для обліку надходжень і витрат роти за категоріями потреб (пальне, харчування, ремонт техніки, дрони тощо). Доступ закрито спільним паролем.

## Що вміє

- **Вхід за паролем.** Пароль задається змінною `APP_PASSWORD`. Після 10 невдалих спроб вхід з тієї ж адреси блокується на 15 хвилин. Зміна пароля завершує всі відкриті сесії.
- **Операції.** Надходження та витрати з датою, сумою, категорією, контрагентом («від кого» / «кому») і описом. Їх можна редагувати й видаляти.
- **Категорії.** Додавання, перейменування, архівування (категорія з операціями не видаляється, лише ховається з вибору для нових записів).
- **Звіт.** За будь-який період по кожній категорії: залишок на початок, надійшло, витрачено, залишок на кінець, плюс підсумок.
- **Фільтри та експорт.** Пошук операцій за періодом, типом, категорією й текстом; вивантаження в CSV, який відкривається в Excel.

## Запуск

Потрібен лише Node.js 22.5 або новіший. Сторонніх залежностей немає, база даних SQLite вбудована в Node.

```bash
APP_PASSWORD='надійний-пароль' npm start
# відкрийте http://localhost:3000
```

### Через Docker

```bash
echo "APP_PASSWORD=надійний-пароль" > .env
docker compose up -d --build
```

Дані зберігаються в томі `oblik-data` (файл `/data/oblik.db`).

## Налаштування

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `APP_PASSWORD` | Пароль для входу (обов'язково) | — |
| `PORT` | Порт сервера | `3000` |
| `DATA_DIR` | Тека з базою даних | `./data` |
| `SESSION_DAYS` | Скільки днів діє вхід | `7` |
| `COOKIE_SECURE` | `1`, якщо сайт працює через HTTPS | вимкнено |
| `TRUST_PROXY` | `1`, якщо перед застосунком стоїть проксі (nginx, Caddy, хостинг) | вимкнено |

## Резервні копії

Уся інформація лежить в одному файлі `oblik.db`. Достатньо регулярно копіювати його (наприклад, `sqlite3 oblik.db ".backup backup.db"`) або вивантажувати CSV з вкладки «Операції».

## Розгортання в інтернеті

Застосунок можна запустити на будь-якому VPS з Docker або на хостингу, що підтримує Node.js і постійний диск (Render, Railway, Fly.io). Обов'язково використовуйте HTTPS і задайте `COOKIE_SECURE=1` та `TRUST_PROXY=1`.
